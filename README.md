# 🎲 Ludo Game (2 Player Version) in C++

This is a terminal-based ASCII Ludo game written in C++ for **2 players only** (Red and Blue). It simulates basic Ludo gameplay mechanics including:

- Dice rolling
- Entering the board with 6
- Token movement with animation
- Safe zones
- Killing other tokens
- Winning when all 4 tokens are finished

---

## 🔧 Features

- 🎮 2 Player support (Red vs Blue)
- 🎲 Dice rolling system
- 🧠 Safe zone logic (no kill in safe cells)
- ⚔️ Kill system (send enemy tokens back to base)
- ✅ Win condition (all 4 tokens finished)
- 🖥 ASCII board rendering in terminal
- 💬 Clear game instructions and token selection
